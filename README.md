# SAMIYAL website starter

A responsive dark charcoal / silver / electric-blue website for the SAMIYAL software brand.

## Files
- `index.html` — home page
- `privacy.html` — starter website privacy policy (review before publishing)
- `support.html` — support page (replace placeholder email before publishing)
- `styles.css` — responsive styling

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload all four files to the root of that repository.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. After deployment completes, visit `https://YOUR-USERNAME.github.io`.

If you prefer to use an organization GitHub account, the site address is based on that account's name.

## Before publishing
- Replace `[ADD YOUR SUPPORT EMAIL BEFORE PUBLISHING]` in `support.html` with an email address you control.
- Review `privacy.html` to ensure it accurately describes the actual site and apps.
- The site intentionally does not claim that SAMIYAL is an incorporated or registered company.
- This website is a starting point. A website by itself does not establish legal business status or guarantee Google Play organisation verification.

## Google Play website verification
Google's current guidance requires registering the website in Google Search Console and associating it with your developer account. Use the same Google account for Search Console and Play Console when possible. Follow the exact instructions in your console:
https://support.google.com/googleplay/android-developer/answer/16260648
